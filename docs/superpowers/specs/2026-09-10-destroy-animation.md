# 奶蛙坐压摧毁动画

用户指定：销毁1 → 销毁2 → 销毁3 → 销毁1倒放（不镜像） → 摸屁股闻手。销毁2完成时立刻移入回收站，后半段继续播放，不等待全部动作结束。

实现：五个独立一次性动画段，状态机依次衔接；第二段完成产生一次性回收事件，末段完成才退出会话。绿幕素材沿用现有抠色方法，独立生成新目录，保持既有角色比例与公共画布。使用坐压接触点而非窗口中心对准文件图标。用户在看到衔接问题后确认第四段改为原片倒放、不镜像，优先保证侧身站姿→正面→闻手连贯。倒放已烘焙进序列帧，运行时不再次倒放。回收失败有反馈，不反复尝试；此前拖动取消不回收，回收后的拖动只中断余下动画。

验证：检查关键帧和动作衔接；测试第二段前不回收、第二段末只回收一次、后续完成正常返回待机、失败不重试和取消不误删；使用临时文件进行完整动作与回收验证。
