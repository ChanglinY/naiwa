# 奶蛙桌面摧毁 — 设计说明

日期：2026-08-20  
状态：待实现

## 1. 要做成什么样

奶蛙在跑的时候，用户在**桌面图标**上右键，菜单里出现「召唤奶蛙摧毁」。点了之后全屏出现淡淡的半透明奶蛙头像和「你要销毁哪个文件？」。用户再左键点中**刚才那个**图标，奶蛙跑过去播摧毁动画，结束后该项目进回收站。

成功标准：

- 没开奶蛙时，桌面右键里没有这一项。
- 开着奶蛙时，用户桌面和公用桌面上的文件、文件夹、快捷方式都有这一项。
- 点对才删除；点错会提醒，文件不动。
- 删除走系统回收站，不永久抹盘。
- 快捷方式只回收 `.lnk` 自己，不跟到真实目标。

## 2. 明确不做

- 资源管理器普通窗口里的文件（路径不在桌面目录的都不做）。
- 奶蛙没运行时自动启动、或菜单仍显示。
- 一次摧毁多个选中项。
- 永久删除、粉碎、清空回收站。
- 自定义 COM 图标以外的资源管理器皮肤。
- 第一版不做专用摧毁序列帧（状态机先接通，画面用现有动作占位）。

## 3. 用户流程

1. 奶蛙已在运行。用户在桌面某图标上右键，选「召唤奶蛙摧毁」。
2. 全屏覆盖层出现：半透明暗底、淡奶蛙头像、中央台词「你要销毁哪个文件？」。覆盖层拦住鼠标，避免点下去打开文件。
3. 左键点中**同一个**图标：覆盖层淡出，奶蛙跑向该图标。
4. 点中别的图标或点空白：头像轻晃，台词改成「不是这个」，约 1.2 秒后改回原句。覆盖层不关。
5. Esc 或在覆盖层上右键空白：取消，文件不动。
6. 奶蛙到达后播摧毁动作，播完把该项目送进回收站，然后回日常行为。

右键多选时：只锁定并摧毁用户右键时交给扩展的那一个项目（通常是焦点项），忽略其余选中项。

## 4. 架构

两个进程，扩展不删文件、不画窗口。

```
Explorer --(右键)--> NaiwaShell.dll
                        | 互斥量？路径在桌面？
                        | 否 → 不插入菜单
                        | 是 → 显示「召唤奶蛙摧毁」
                        v
                   命名管道写 UTF-8 路径
                        v
                   Naiwa.exe（已在跑）
                        v
              覆盖层确认 → 跑位 → 动画 → IFileOperation 回收
```

约定：

| 机制 | 用途 |
|---|---|
| 命名互斥量 `Local\NaiwaPet.Running` | DLL 判断奶蛙是否在跑 |
| 命名管道 `\\.\pipe\NaiwaDestroy` | 只传一条目标路径（UTF-8，单行，无额外 JSON） |
| HWND / 窗口标题不作为主判定 | 避免改名或多语言导致菜单消失 |

奶蛙进程启动时创建互斥量并打开管道服务；退出时释放。DLL 在用户退出奶蛙后仍可留在资源管理器里，只是查不到互斥量就不插菜单。

## 5. 模块

### 5.1 `shell/NaiwaShell/`（C#，net8.0-windows，x64）

COM 进程内扩展，给 64 位 Explorer 用。

- 实现 `IShellExtInit` + `IContextMenu`（经典菜单 /「显示更多选项」）。Windows 11 第一层现代菜单留作后续，不挡这一版。
- `QueryContextMenu` / `GetState`：互斥量不存在、或路径不在桌面，则插入 0 个项。
- 桌面路径：`FOLDERID_Desktop` 与 `FOLDERID_PublicDesktop` 的规范化前缀匹配（含它们的子文件夹里、但又放在桌面命名空间下的情况：仅当完整路径以这两个根目录之一为前缀）。
- `Invoke`：连接管道，超时 300ms，写入路径后断开。失败静默，不 `MessageBox`。
- 不启动 `Naiwa.exe`。

注册：

- 当前用户 HKCU 注册 COM，ContextMenuHandler 只挂在 `AllFilesystemObjects` 上一次，避免文件/文件夹菜单里出现两项。桌面过滤仍在 DLL 里做。
- 奶蛙**首次成功启动**时尝试注册；已注册则跳过。
- 退出时**不反注册**。卸载/开发用 `shell/NaiwaShell/unregister.ps1`。
- 不要求管理员。

### 5.2 奶蛙进程内

| 单元 | 职责 |
|---|---|
| `src/single_instance.py` | 创建/持有互斥量；第二份实例直接退出 |
| `src/destroy_ipc.py` | 后台线程听管道，把路径抛到 Qt 主线程 |
| `src/destroy_overlay.py` | 全屏覆盖层窗口、台词、晃头、点击命中转发 |
| `src/desktop_icons.py` | 枚举桌面图标屏幕矩形与路径，把点击映射到项目 |
| `src/recycle.py` | `IFileOperation` 删除到回收站，不弹自定义确认框 |
| `src/behavior.py` | 新增摧毁移动/播放状态，确认期间冻结日常 AI |
| `src/config.py` | 注册 `destroy` 动作（可先指向现有帧目录作占位） |
| `src/main.py` / `pet_window.py` | 接线：IPC → 覆盖层 → 追逐目标 → 回收 |

覆盖层与桌宠是两个窗口：覆盖层 `WindowStaysOnTop` 且高于桌宠，确认结束再降下。确认期间桌宠可隐藏或静止，点对后再现身。

### 5.3 图标命中

覆盖层吃掉点击，必须自己把屏幕坐标对上桌面 `SysListView32`（`Progman` / `WorkerW` 下）的图标。

- 用图标的屏幕矩形做命中；再把该项文本/索引解析成完整路径，与管道锁定的路径做规范化比较（大小写、短路径、末尾斜杠）。
- 点对：以该图标矩形中心为追逐终点（不是鼠标指针，避免停在图标边上）。
- 解析不到路径但矩形命中了「显示名与目标文件名一致」的项：仍算命中（应对偶发的跨进程读文本失败）。
- 多显示器：覆盖层铺所有屏；桌面图标在哪块屏，矩形就用哪块屏的坐标。注意 DPI。

## 6. 覆盖层表现

- 铺满所有屏幕。暗底约 40% 黑/暖褐，中央大号半透明头像（现有捧腹或正面待机帧，透明度约 20–35%），其下台词。
- 确认成功：覆盖层约 250ms 淡出。
- 点错：水平轻晃一次 +「不是这个」；1.2s 后恢复原句。
- 确认期间忽略拖拽、追鼠标、自动蹲下。Esc 与右键空白取消后立即恢复。

## 7. 跑位、动画、回收

点对之后：

1. 若当前是蹲/互动，先打断，按现有姿势规则切到可爬行。
2. 复用 `crawl_down → crawl → crawl_up` 链，追逐目标改为图标中心对应的窗口位置（与现有追鼠标相同的坐标含义：窗口左上角期望值，需按画布锚点换算到「脚/身体对准图标」）。
3. 到达阈值内：播放 `destroy`。`config.ACTIONS["destroy"]` 第一版 `folder` 暂指向 `laugh`，`loop=False`，播完进入回收。有专用帧后再只改 folder。
4. `recycle.send_to_recycle_bin(path)` 使用 `IFileOperation`，标志包含允许撤销、进回收站。尽量 `FOF_NOCONFIRMATION`，让仪式代替系统确认框。若组策略仍弹出系统对话框，用户取消视为失败。
5. 成功：回捧腹待机。失败：不重试删除，屏幕上短时字幕说明原因（见 §8）。

删除**只发生在动画结束之后**。动画播到一半取消不了已经点对的仪式，但进程被杀则不会删（没走到 API）。

## 8. 失败与边界（自行约定）

| 情况 | 处理 |
|---|---|
| 管道超时/没人听 | DLL 静默；用户无反馈（此时奶蛙按约定应在跑，属于异常） |
| 锁定路径在覆盖层出现前被删/挪走 | 覆盖层仍出；点原位置算点错；若能发现文件已消失，台词改为「已经没了」，3 秒后自动关 |
| 文件占用 / 无权限 / 回收站不可用 | 动画照常播完，删除失败，字幕一句原因，图标还在 |
| 只读文件 | 交给 `IFileOperation`；系统若仍要确认，听用户 |
| 桌面命中 API 失败 | 无法点对则永远点错；Esc 可退。日志记一笔 |
| COM 注册失败 | 桌宠照常跑，没有右键项。日志警告 |
| 第二份奶蛙 | 互斥量挡住，新进程退出 |
| 摧毁过程中用户拖奶蛙 | 确认阶段不可拖；跑位阶段可被拖，视为取消摧毁且不删除 |
| 路径是目录 | 回收整个文件夹（系统回收站语义） |

## 9. 测试

- 单元：桌面路径前缀；路径规范化相等；点击矩形命中。
- 手动：奶蛙关/开时菜单有无；文件/文件夹/快捷方式；点错提醒；Esc 取消；动画结束后回收站里能找到并可还原；占用中的文件失败且仍在；多屏。
- `tools/smoke_test.py` 不依赖 COM，启动后几秒退出的行为保持。可加可选环境变量跳过注册，避免无头 CI 写 HKCU。

## 10. 文件布局（预计）

```
shell/NaiwaShell/          # C# COM 工程、register/unregister 脚本
src/single_instance.py
src/destroy_ipc.py
src/destroy_overlay.py
src/desktop_icons.py
src/recycle.py
src/behavior.py            # 扩展状态
src/config.py              # destroy 动作
src/pet_window.py          # 接线
src/main.py                # 启动注册与 IPC
docs/superpowers/specs/2026-08-20-desktop-destroy-design.md
```

打包：shell 扩展 DLL 复制到 `%LOCALAPPDATA%\Naiwa\NaiwaShell.dll` 再注册。不要只放在 PyInstaller 单文件的临时解压目录里，否则资源管理器会加载失败或每次换路径。
